# Sea Battle

Графическая реализация классической настольной игры «Морской бой» с поддержкой классического прямоугольного поля и **шестиугольного поля в виде пчелиных сот**. Игрок может вручную расставлять свои корабли или доверить автоматическую расстановку, после чего сразится с умным или случайным ботом.

## Особенности

- Два типа поля: **классическое** (classic) и **шестиугольное** (hex).
- Ручная и автоматическая расстановка кораблей.
- Умный бот с алгоритмом цели (добивание подбитых кораблей).
- Настраиваемый размер поля и состав флота.
